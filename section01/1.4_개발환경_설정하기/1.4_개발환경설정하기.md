## Node 시작하기

### 1.4.1 노드 설치하기

- 운영체제별로 노드를 설치하는 방식은 비슷하다.
- GUI를 사용하므로 웹 브라우저를 통해 설치한다. 터미널로 설치한다.

#### 윈도우

- 노드 공식 사이트 (https://nodejs.org)에 접속한다.

- LTS와 Current 버전 중 최신 버전을 설치한다
```bash
kimyohan@ node.js_tutorial % node -v
v24.3.0
```

> **Note = LTS와 Current 버전 차이**
> - LTS: 기업을 위해 3년간 지원하는 버전이다. 짝수 버전만 LTS 버전이 될 수 있다. 서버를 안정적으로 운영해야 할 경우 선택한다. 하지만 최신 기능은 사용하지 못할수도 있다.
> - Current: 최신 기능을 담고 있는 버전이다. 다소 실험적인 기능이 들어 있어 예기치 못한 에러가 발생할 수 있다. 서버에 신기능이 필요하거나 학습용으로 사용할 때 적절하다. 짝수 버전은 나중에 LTS가 되어 Current일 때 사용하는 것을 고려해볼만 하다.
> - 홀수버전: 노드는 6개월마다 버전을 1씩 올린다. 따라서 18버전 이전에 17버전도 있다. 하지만 홀수 버전은 LTS를 지원하지 않아 18버전이 나오면서 17버전이 사라졌다. 나중에 19버전이 나오면 18버전이 LTS가 되고 19 버전이 Current가 된다.

- 노드 런타임, 노드 패키지 관리자, 온라인 문서 바로가기, 명령 프롬프트에서 노드 명령어를 사용할 수 있게 해주는 시스템 환경 변수다. 기본적으로 모두 설치된다.
- Tools for Native Modules 화면에서 체크박스에 체크 표시를 하고 Next를 눌러 다음으로 넘어간다.

- 노드 설치가 끝나면 추가 도구 설치 화면이 뜨고 아무 키나 눌러 설치를 진행한다.
- 중간에 사용자 계정 컨트롤 창이 나오면 예 버튼을 눌러 설치를 시작한다.
- 설치가 끝나면 Type ENTER TO exit가 표시된다.

- 나중에 npm(노드 패키지 매니저)을 사용해야 하므로 npm이 제대로 설치되었는지도 확인한다.
```bash
kimyohan@ node.js_tutorial % npm -v
11.4.2
```

> **Node = 환경 변수 확인**
> node나 npm 명령어를 사용했을 때 에러가 발생하면 환경 변수가 제대로 설정되어 있는지 확인해야 한다. 윈도우에서는 터미널 `echo $PATH$`를 입력해 환경 변수 목록을 확인할 수 있다.
> 결과를 출력되는 경로 중에 노드가 설치된 경로가 들어 있지 않으면 명령어 실행 시 에러가 발생한다.

- 윈도우에서 명령 프롬프트를 통해 노드를 설치하고 싶다면 초콜리티(chocolately)를 고려해도 된다.
- 초콜리티는 노드 외의 다른 프로그램도 명령 프롬프트를 통해 설치할 수 있어 편리하다.
- 링크(https://chocolatey.org/install)의 절차를 참고해 초콜리티를 설치합니다.

#### 맥

- 방식은 위와 거의 같다.

> **Note = 환경 변수 확인**
> node나 npm 명령어를 사용했을 때 에러가 발생하면 환경 변수가 제대로 설정되어 있는지 확인해봐야 한다. 
> 맥에서 터미널에서 echo $PATH를 입력해 환경 변수 목록을 확인할 수 있다.

- 터미널
```bash
kimyohan@ node.js_tutorial % echo $PATH
/Users/kimyohan/Library/Python/3.9/bin:/Users/kimyohan/Library/Python/3.9/bin:/opt/homebrew/bin:/opt/homebrew/sbin:/usr/local/bin:/System/Cryptexes/App/usr/bin:/usr/bin:/bin:/usr/sbin:/sbin:/var/run/com.apple.security.cryptexd/codex.system/bootstrap/usr/local/bin:/var/run/com.apple.security.cryptexd/codex.system/bootstrap/usr/bin:/var/run/com.apple.security.cryptexd/codex.system/bootstrap/usr/appleinternal/bin:/opt/pmk/env/global/bin:/Users/kimyohan/Library/Python/3.9/bin
```

- 결과로 출력되는 경로 중에 노드가 설치된 경로가 들어 있지 않으면 명령어 실행 시 에러가 발생한다.
- 없다면 다음 명령어를 사용해 PATH 환경 변수에 노드 설치 경로를 추가하면 된다.
```bash
$ export PATH=$PATH: 노드 설치 경로
```

- 다시 `echo $PATH`를 실행해 노드 설치 경로가 제대로 들어 갔는 지 확인한다.

> **Note = Homebrew로 노드 설치하기**
> 터미널을 통해 노드를 설치하고 싶으면 Homebrew를 사용하면 된다. 다음 명령어를 터미널에 입력해 Homebrew를 설치한다.

```bash
$ /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/master/install.sh)"
```

- Homebrew 설치가 완료되면 `brew install node` 명령어로 노드를 설치하면 된다.
