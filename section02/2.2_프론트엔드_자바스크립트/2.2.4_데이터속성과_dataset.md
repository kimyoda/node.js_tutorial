#### 2.2.4 데이터 속성과 dataset

- 노드를 웹 서버로 사용하는 경우, 클라이언트(프런트엔드)와 빈번하게 데이터를 주고받게 된다.

- 첫 번째로 고려해야 할 점은 보안이다. 프론트엔드에 민감한 데이터를 내려보내는 것은 좋지 않다.
- 보안과 관련이 없는 데이터들은 자유롭게 해도 상관이 없다.
- HTML과 관련된 데이터를 저장하는 공식적인 방법도 있다.
- 데이터 속성이다.

```html
<ul>
  <li data-id="1" data-user-job="programmer">Zero</li>
  <li data-id="2" data-user-job="designer">Nero</li>
  <li data-id="3" data-user-job="programmer">Hero</li>
  <li data-id="4" data-user-job="ceo">Kero</li>
</ul>
<script>
  console.log(document.querySelector("li").dataset);
  // { id: '1', userJob: 'programmer' }
</script>
```

- HTML 태그의 속성으로 data로 시작하는 것들을 넣는다. 데이터 속성이다.
- data-id, data-user-job을 주었다.
- 웹 애플리케이션 구동에 필요한 데이터들이다.
- 자바스크립트로 쉽게 접근할 수 있다.
