#### 2.2.1 AJAX

- AJAX(Asynchronous Javascript And XML)는 비동기적 웹 서비스를 개발할 때 사용하는 기법이다.
- 이름에 'XML'이라는 용어가 들어갔지만 XML을 사용해야 하는 것은 아니다.
- 요즘에는 JSON을 많이 사용한다.
- 페이지 이동 없이 서버에 요청을 보내고 응답을 받는 기술이다.
- 요청과 응답은 4.1에 설명이 되어 있다.
- 웹 사이트 중 페이지 전환 없이 새로운 데이터를 불러오는 사이트는 대부분 AJAX 기술을 사용한다고 생각하면 된다.

- AJAX 요청은 jQuery나 axios 같은 라이브러리를 이용해서 보낸다.
- 브라우저에서 기본적으로 XMLHttpRequest나 fetch 객체를 제공하나, 사용 방법이 복잡하고 서버에서 사용할 수 없어 (fetch는 노드에서 사용할 수 있으나 실험)
- 전반적으로 axios를 사용
- HTML파일을 하나 만들고 안에 script 태그를 추가한다.

```html
<script src="https://unpkg.com/axios/dist/axios.min.js"></script>
<script>
  // 여기에 예제 코드를 넣으세요
</script>
```

- 요청의 종류 중 하나인 GET 요청을 보내본다. 4.2 절에서 다룰 REST API를 다룬다.
- axios.get 함수의 인수로 요청을 보낼 주소를 넣으면 된다.

```html
<script src="https://unpkg.com/axios/dist/axios.min.js"></script>
<script>
  axios
    .get("https://www.zerocho.com/api/get")
    .then((result) => {
      console.log(result);
      console.log(result.data); // {}
    })
    .catch((error) => {
      console.error(error);
    });
</script>
```

- 이번에는 POST 방식의 요청을 보냈다. POST요청에는 데이터를 서버로 보낼 수 있다.

```html
<script src="https://unpkg.com/axios/dist/axios.min.js"></script>
<script>
  (async () => {
    try {
      const result = await axios.post("https://www.zerocho.com/api/post/json", {
        name: "kimyohan",
        birth: 1992,
      });
      console.log(result);
      console.log(result.data);
    } catch (error) {
      console.log(error);
    }
  })();
</script>
```

**GET vs POST 요약**

| 요청 방식 | 메서드                  | 용도             | 데이터 전송     |
| --------- | ----------------------- | ---------------- | --------------- |
| GET       | `axios.get(url)`        | 데이터 조회      | URL 쿼리스트링  |
| POST      | `axios.post(url, data)` | 데이터 전송/생성 | 요청 본문(body) |

- 전체적인 구조는 비슷한데, 두 번째 인수로 데이터를 넣어 보내는 것이 다르다.
- GET 요청이면 axios.get을 사용, POST 요청이면 axios.post를 사용한다.

> **💡 추가 개념**
> axios의 응답 객체(`result`)는 `status`(HTTP 상태 코드), `headers`(응답 헤더), `data`(실제 데이터) 등을 포함한다.
> `async/await`는 ES2017에 도입된 문법
> 요청/응답 인터셉터, 요청 취소, 자동 JSON 변황 등 fetch보다 다양한 기능을 제공한다.
