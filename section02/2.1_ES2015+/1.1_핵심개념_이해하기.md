### 2.1 ES2015+

- 바로 ES2015(ES6라고도 한다)가 등장. 3년전 기준으로 ES2023, 현재는 ES2026까지 나왔다.
- 바벨(babel)처럼 구형 브라우저에 맞게 문법을 변환해주는 도구가 널리 쓰여 문제가 되지 않는다.


#### 2.1.1 const, let

- 자바스크립트를 배울 때 var로 변수를 선언하는 방법부터 배운다. 하지만 vat은 이제 const와 let이 대체한다.
- const와 let이 공통적으로 갖는 블록 스코프(범위)에 대해 확인하자.
```js
if (true) {
  var x = 3;
};
console.log(x); // 3

if (true) {
  const y = 3;
};
console.log(y); // Error
```

- 코드는 크롬 개발자 도구의 Console탭으로 테스트 할 수 있다.
- x는 정상적으로 출력되나 y는 에러가 발생한다. 

- var는 함수 스코프를 가져 if문의 블록과 관계없이 접근할 수 있다.
- const, let은 블록 스코프를 가져 블록 밖에서는 변수에 접근할 수 없다.
- 블록의 범위는 중괄호이다. 
- 함수 스코프 대신 블록 스코프를 사용함으로 호이스팅 같은 문제도 해결되고 코드 관리도 수월하다.

- const, let과 var는 스코프 종류가 다르다.
- const는 한 번 값을 할당하면 다른 값을 할당할 수 없다. 다른 값을 항당하려고 하면 에러가 발생한다.
- 초기화할 때 값을 할당하지 않으면 에러가 발생한다.
- const로 선언한 변수를 상수라고 한다.
```js
const a = 0;
a = 1;

let b = 0;
b = 1;

const c; 
```

> **Note = const, let중 사용**
> 한 번 초기화했던 변수에 다른 값을 할당하는 경우는 생각보다 적다.
> 변수 선언 시에는 기본적으로 const를 사용, 다른 값을 할당해야 하는 상황이 생겼을떄는 let을 사용하면된다.
